# 収支ダッシュボード（kakeibo）

家計の収支を可視化する、単一 HTML ファイルの Web アプリです（`index.html` のタイトル「収支ダッシュボード」に基づく）。

## できること

タブ構成は `index.html` の実態に基づきます。

- **ダッシュボード**: 収支の集計やグラフ表示（Chart.js 使用）
- **CSV取り込み**: 収支 CSV をドラッグ＆ドロップで取り込み。資産推移 CSV の取り込みにも対応（任意）
- **手動入力**: CSV を使わない収支の手入力
- **確定申告**: 税務・確定申告に関する計算／確認用の画面

入力データはブラウザの `localStorage`（キー接頭辞 `kakeibo_`）に保存されます。

## 開き方

`index.html` をブラウザで開いてください。ビルドは不要です。

グラフ表示には CDN（cdnjs）から Chart.js 4.4.1、フォントには Google Fonts を読み込むため、表示にはインターネット接続が必要です。

### バックアップ復元の安全確認

復元前に既知のデータ型を検証し、不正な金額・ID・配列や未対応バージョンは保存前に拒否します。旧バックアップで欠けている項目は現在の値を維持し、含まれる項目だけを上書きします。保存途中で失敗した場合は書き込んだキーを元に戻します。復旧自体も失敗した場合、元データのスナップショットをページ内に保持して追加保存を止めます。再読み込みする前に「バックアップを書き出す」で元データを保存してください。ページを閉じた後のスナップショット復元は保証できません。

回帰テスト: `node --test tests/*.test.mjs`。実ブラウザ・実データによる復元確認は別途必要です。

## 継続的な回帰確認

`node .github/scripts/check.mjs`、`node --test tests/*.test.mjs` と CSV 取り込みブラウザ QAを PR と `master` への push で実行します。回帰 workflow は手動でも実行できます。Pages の配信成功とは別に、対象コミットの回帰結果を確認してください。実端末・実利用者の評価や外部サービスの本番状態は、この自動テストの保証範囲に含みません。
