# 収支ダッシュボード（kakeibo）

家計の収支を可視化する、単一 HTML ファイルの Web アプリです（`index.html` のタイトル「収支ダッシュボード」に基づく）。

## できること

タブ構成は `index.html` の実態に基づきます。

- **ダッシュボード**: 収支の集計やグラフ表示（Chart.js 使用）
- **CSV取り込み**: 収支 CSV をドラッグ＆ドロップで取り込み。資産推移 CSV の取り込みにも対応（任意）
- **手動入力**: CSV を使わない収支の手入力
- **確定申告**: 税務・確定申告に関する計算／確認用の画面

入力データはブラウザの `localStorage`（キー接頭辞 `kakeibo_`）に保存されます。

## 開き方

`index.html` をブラウザで開いてください。ビルドは不要です。

グラフ表示には CDN（cdnjs）から Chart.js 4.4.1、フォントには Google Fonts を読み込むため、表示にはインターネット接続が必要です。
